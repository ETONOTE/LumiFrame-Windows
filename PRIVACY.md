# LumiFrame Windows privacy notice

Updated October 15, 2026. This notice covers the Windows portable beta, not the separate Android app.

## Media processing

LumiFrame opens the media you choose and processes it on your computer. The Windows app does not require an account and does not upload your images or videos to an upscaling service. Conversion results are written to the location you choose. Keep your originals.

## Local files and diagnostics

Preferences, GPU execution caches and diagnostic files can be stored locally. Diagnostics may include file paths, media properties, selected engine, hardware information and errors. Local processing does not mean these files are safe to publish without review.

Before sharing a screenshot or report, remove personal filenames and paths, usernames, email addresses, device identifiers, access tokens and private media. Do not attach a complete project folder, cache, crash dump or unreviewed log to a public issue.

## Downloads and support

GitHub hosts downloads and issue reports. Opening a website or submitting a report uses that service under its own privacy terms. GitHub issues and their attachments are public. Share only the minimum technical information needed to reproduce a problem.

The release package excludes tester contact lists, signing keys, local credentials, private media, development logs and reference-device execution plans. This packaging check is separate from how you manage files created while using the app.

For a non-sensitive question, use [LumiFrame support](https://github.com/ETONOTE/LumiFrame-Windows/issues). Never post passwords, private keys or identification documents there.
